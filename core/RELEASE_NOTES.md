# 弹幕排队姬 v3.0.17

`v3.0.17` 为正式版发布。

## 本次发布

- 以 `v3.0.16` 实际发布代码为基线；
- 业务代码、功能与行为保持不变；
- 仅将发布版本号更新为 `3.0.17`；
- 本次按 **Release（正式版）** 发布。

## 发行文件与下载

普通用户只需要下载对应平台的完整便携版 ZIP：

- Windows 客户端：`BiliPDJ-v3.0.17-Windows-Tk-Portable-x64.zip`
- Web 便携版：`BiliPDJ-v3.0.17-Web-Portable-x64.zip`

内置更新器仍会使用对应的文件清单、增量资源包、`update-manifest.json` 与 SHA-256 校验信息。
