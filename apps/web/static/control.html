    关于
    弹幕排队姬 Web 控制台
    
        
    弹幕排队姬
    面向 Bilibili / 抖音直播间的弹幕排队管理工具。后端是唯一业务状态源，Web 与 Windows 客户端只负责管理和展示。
    Web 控制台依赖正在运行的后端，因此服务启动/停止由 Web Portable 启动器负责；浏览器页负责与 Windows Tk 对齐的日常管理功能。
    本软件免费、源码公开。若有人单独售卖软件本体，请谨慎核实来源。
